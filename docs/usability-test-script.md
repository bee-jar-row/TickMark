# Usability Test Script (Group 7)

Run this with 2–3 students per group member (takes ~5–10 minutes per person).

## Before starting
- Open the HTTPS TickMark link on the participant's phone.
- Turn on notifications when prompted (on iOS, use Share -> Add to Home Screen first).
- Tell them to think out loud and not worry about breaking anything.

## Tasks

1. **First impression & ranking**
   Ask them to look at the list and tell you what TickMark thinks they should do first, and why. Check if they notice the one-line reason and the "How is this list ranked?" toggle.

2. **Deadline moved (C1)**
   Tell them Essay 2's deadline got pushed back by 1 day and ask them to update it. See if they use "Deadline extended" (+1 day or the picker) and notice the rank change.

3. **Progress update (C2)**
   Ask them to mark a task as 50% done. Check if they find "Already started" and see the reason line update.

4. **Manual reorder & Undo (C4)**
   Ask them to move a lower task to the top, then undo it or go back to the app's order. Check if "moved by you", Undo, and "Use app order again" make sense.

5. **Settings, alerts & backup**
   Ask them to turn on Quiet class mode, trigger a test alert, and export a JSON backup. Check if the alert buttons (Open task / Remind in 30 min) are clear.

## Quick questions after
- Did the one-line reasons make sense? (1–5)
- Did you trust the order it gave you? Why or why not? (1–5)
- Was it easy to fix mistakes or override the list? (1–5)
- Would the start-by alert + Quiet class mode work for you in real life? (1–5)
- Anything confusing or annoying?
