# TickMark — HCI Usability Test Script (Group 7)

Use this 5–10 minute script for each student participant (2–3 participants per group member = 6–9 total).

## Setup (Before Starting)
1. Open the live HTTPS TickMark URL on the participant's phone (or test device).
2. If testing background alerts: tap **Turn on** to allow notifications (on iPhone, *Share → Add to Home Screen* first).
3. Ask the participant to **think aloud** as they tap through the app.

---

## Tasks

### Task 1: Understand the Ranked List (Trust & Transparency)
- **Prompt:** *"Look at your current list. Which task does TickMark say you should work on first, and why?"*
- **Observe:**
  - Can they read the urgency tag (`START NOW` / `START TODAY` / `LATER`) and the one-line reason?
  - Do they notice **"How is this list ranked?"** if they want to check the formula?

### Task 2: Handle a Changed Deadline (C1 — Deadline Extended)
- **Prompt:** *"Your lecturer just moved the Essay 2 deadline by 1 day. Update it in the app."*
- **Observe:**
  - Do they find **Deadline extended** (+1 day / date picker) easily?
  - Do they notice the rank/start-by time updates immediately?

### Task 3: Report Progress (C2 — Already Started)
- **Prompt:** *"You already finished 50% of one task. Update your progress."*
- **Observe:**
  - Can they find **Already started** and adjust the slider?
  - Does the reason line update to show `50% done`?

### Task 4: Override & Recover (C4 — Human-in-the-Loop + Undo)
- **Prompt:** *"Move a lower-ranked task to the top because you feel like doing it first, then undo or switch back to the app's order."*
- **Observe:**
  - Do they use the `▲ / ▼` reorder buttons and notice the **"moved by you"** indicator?
  - Can they use **Undo** or **Use app order again** without confusion?

### Task 5: Alerts, Quiet Mode & Backup
- **Prompt:** *"Open Settings, turn on Quiet class mode (vibration only), trigger a test alert, and export a backup of your tasks."*
- **Observe:**
  - Can they find **Quiet class mode**, **Test alert here / Test push**, and **Export JSON**?
  - Does the alert dialog clearly offer **Open task** and **Remind in 30 min**?

---

## Post-Test Questions (1–5 Scale + Short Note)
1. **Clarity:** *How clear was the one-line reason for each task's rank?* (1–5)
2. **Trust:** *Did you trust the app's ranking order, and why/why not?* (1–5 + note)
3. **Control:** *Did you feel in control when overriding the order or fixing mistakes (Undo)?* (1–5)
4. **Alerts:** *Would the start-by alert + Quiet class mode work for your daily routine?* (1–5 + note)
5. **Biggest friction:** *What was the most confusing or annoying part?*
